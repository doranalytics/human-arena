# Small teaching pilot

Test five representative capabilities before rewriting the curriculum. Use Constraints, Interview me, Refine it, Fact-check and Hand it off (look up their current titles in the challenge catalogue).

For each participant:

1. Let them complete the challenge using its current instructions and sample material. Record confusion, hints, retries and any grading disagreement.
2. Ask them to explain the capability in their own words.
3. Give them a different supplied example with the same underlying skill. Do not repeat the menu steps or supply a prompt to copy.
4. Observe whether they can choose and apply the technique independently. Ask when they would use it in their own life.

Judge learning by independent transfer and a correct explanation, not speed alone. Separate failures to find a control from failures to understand the technique, and both from incorrect grading. Preserve successful patterns; revise only demonstrated problems. Review every disputed result against the exact criteria shown at attempt start.

This is a pilot plan, not completed user research. No new arrows, autoplay examples or automatic grading are introduced by this release.
